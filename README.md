# 🏗️ BuildCalc — Construction Cost Estimator for India

A live web application that helps homeowners, contractors, 
and builders across India estimate construction costs 
accurately and instantly.

## 🔗 Live Demo
[buildcalc-india.netlify.app](https://buildcalc-india.netlify.app)

## ✨ Features
- Material cost calculation (cement, steel, bricks, sand)
- City-specific rates for Hyderabad, Bangalore, Mumbai, Delhi NCR
- GST (18%) calculation and wastage factor adjustments
- Black Cotton Soil foundation surcharge
- Contractor profit margin calculator
- Stage-wise payment schedule generator
- WhatsApp sharing for instant estimate sharing

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript
- Deployed on Netlify

## 💡 Problem Solved
Most Indian homeowners overpay contractors because they 
have no way to verify estimates independently. BuildCalc 
gives them accurate, transparent cost breakdowns in seconds.
